# Tholin’s KiCad Library

A KiCad library filled with whatever components I had to deal with over the years.

## Contents (Symbols)

Old CPUs and Microcontrollers - 8X305, 6507, 8085, 80386, 80960CA, HD6120, HD404729, MB86901, MK3850, NS32016, (WD)65C02, Z180, D8749, MC14500

ROMs - 27C160, 28C16, SCN2670

SRAMs - 61LV256, AS1C2M16P, AS6C6416, AS7C256A-10, CDP1824, HM628512, HY6116AL(P), IS61C256, IS61WV12816DBLL, IS61WV102416FBLL, MCM6810

DRAMs - LY68L6400, KM4164

Modern Microcontrollers and devboards - nanoCH32V003, PIC16F506

Microprocessor peripherals and coprocessors - 65C22, 81C55, AM9511, CDP1852, CDP1855, EF6850, MB68901, P8251, R65C51, Z84C3010

Microprocessor support chips - MC6785, MK3853, TIM9904

Video chips - SCN2674, TMS9918

Standard logic - 74LS624, SN74LV1T126, SN74LVC8T245

Microcontroller/general-purpose peripherals (SPI and I²C) - DAC7611, DS1233, EPCSx, MAX192, MX25L1005, W25Q32, Y3014

Retro sound chips - SAA1099, SN76489, UM66Txx, YM2203, YM2612, YM3812

East german (GDR/DDR) components - DS8212D, U214, U505, U555, U8001, U8840, UB8002, UB8563

Analog components - INA114, MIC94050, OPA207, SST211, TMV0505, TP4056, TPD4S009

And others - ADV7513, CompactFlash Card, GAL22V10, HT12D, HT12E, ICS501, MC14490, MMC351, MMC4511, SK9822

## Contents (Footprints)

Footprints for these specific components are included: 80960CA, K4T51043QE (with NC pads removed), CompactFlash for Mouser Part No. "517-N7E50-A516PK-30", CompactFlash for Mouser Part No. "517-N7E50-E516PK-30", nanoCH32V003 devboard (named "DIP-22_610_ELL"), intel386DX, MB68901, SK9822, SK9822-EC20 (2020 SMD size)

These generic footprints are included: BGA for x4 DDR2 ICs, narrow DIP64, SOIC-6, TO-220-5 Horizontal (no DRC errors with JLCPCB rules), TSOP-I-28 (pin numbers shifted to fit some IS memory chips)
